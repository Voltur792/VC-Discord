# Поддержка платформ

**Windows — основная платформа. Linux и macOS — экспериментальная поддержка.**

Полная ручная проверка на Linux и macOS ещё не выполнена. Автоматические проверки на Windows, Ubuntu и macOS доступны во вкладке Actions, workflow «Platform checks». Они проверяют зависимости и программную логику, но не заменяют проверку микрофона, звука, окон, системных разрешений и аккаунтов в обычном графическом сеансе.

Astra выпускает хосты плагинов для Windows x64 и Linux x64. macOS и ARM пока зарезервированы без выпускаемого хоста: наличие кода macOS не означает, что плагин уже можно установить в Astra на Mac. См. [официальный список платформ](https://github.com/mihailinl/AstraPlugins/blob/master/astra-plugin-cli/vendor/astra-plugin-manifest/src/platform.rs).

Данные Windows сохраняются в прежних папках. В Linux используются стандартные XDG-папки пользователя, в macOS — `~/Library/Application Support`. Перенос личных ключей и аккаунтов между ОС не выполняется автоматически. `ASTRA_CONFIG_DIR` позволяет указать нестандартную папку конфигурации Astra.

Для собственных настольных окон на Linux нужны зависимости `pywebview[qt]`, а в сеансе Wayland — также Qt Wayland platform plugin. Пользовательские `QT_QPA_PLATFORM` и `PYWEBVIEW_GUI` сохраняются. Работа поверх всех окон и расположение зависят от композитора. Изменения относятся к окнам плагинов; общий оверлей Astra обновляется отдельно разработчиком Astra.

## VC-Discord

В сборке лежат отдельные DAVE-модули для Windows, Linux x64 с glibc и macOS. Linux с musl (например, Alpine) и Linux ARM в этом выпуске не поддерживаются. Сборщик проверяет архивы по SHA512 из package-lock; во время работы ничего не скачивается. Манифест сохраняет x64, поскольку это архитектура выпускаемых хостов Astra. Модули ARM для Windows/macOS подготовлены отдельно, но не означают наличие совместимого хоста Astra.

Python выбирается из bin/python3/bin/python в Linux/macOS; подготовка окружений использует bin/python. Для музыки установите FFmpeg системным пакетным менеджером и нажмите «Подготовить музыку». Скачивание Windows ZIP на других ОС не запускается.

Системный голос: SAPI в Windows, espeak-ng в Linux, say в macOS. Синтез идёт в WAV для Discord, звук на локальных колонках не включается. Другие движки и отдельное подтверждение отправки речи в облако сохраняются.

Windows-ключи сохраняют DPAPI. В Linux/macOS используется AES-256-GCM с отдельным secrets.key (владелец текущего пользователя, права 600) и файлом настроек с правами 600. Это локальная защита доступа по профилю, а не системная Keychain: владелец профиля с обоими файлами способен открыть ключи. При переносе нужны оба файла; DPAPI-файл другого Windows-профиля на Linux/macOS не расшифровывается. Не удаляйте secrets.key отдельно от настроек.

Выбор экрана открывается через xdg-open/open и браузерный диалог разрешений. На Wayland браузеру нужны поддержка PipeWire и настроенный xdg-desktop-portal. Открытие папки отчёта также не использует explorer.exe на других ОС.

Контроль ПК по-прежнему разрешён только Discord ID из настроек. Текстовые заказы музыки/чат не получают доступ к системным действиям.
