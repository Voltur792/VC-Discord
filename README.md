# Voice communication-Discord

Голосовой плагин для [Astra](https://github.com/mihailinl/AstraPlugins) в Discord от **Voltur**. Бот присоединяется к выбранному голосовому каналу, разговаривает с участниками и воспроизводит музыку. Страница настроек в Astra — **VC-Discord**.

[Скачать последнюю версию](https://github.com/Voltur792/VC-Discord/releases/latest)

:exclamation::exclamation::exclamation: **Важно:** Для использования всех функций, включая команды компьютеру, скачайте Source code (zip), распакуйте и **сначала соберите плагин** по инструкции «Установка из исходников» ниже. Затем в Astra откройте **Разработка → Загрузить плагин → Обзор** и выберите распакованную папку. Без сборки файл `dist/index.js` отсутствует и плагин не запустится.

## Возможности

- Голосовой разговор со всеми участниками канала: после каждой реплики или обращения по имени.
- Настройки чата, распознавания речи, голоса и личности из Astra; можно выбрать собственные подключения.
- Whisper, Vosk, Google Web STT и совместимые сервисы распознавания речи.
- Озвучка голосом Astra Supertonic 3, установленным голосом Windows или через совместимый сервис.
- Отдельное сохранение API-ключей для разных подключений модели.
- Обсуждение выбранного окна или экрана с локальной моделью, поддерживающей изображения.
- Музыка из Яндекс Музыки и VK через [Astra Music](https://github.com/Voltur792/astra-music): поиск песен, плейлисты, «Моя волна» и «Мои треки VK».
- Отдельная музыкальная очередь Discord: пауза, продолжение, переключение треков и громкость от 0 до 10. Во время ответа бота музыка становится тише.
- Название песни, исполнитель и источник (Яндекс Музыка или VK) в статусе бота. На паузе появляется отметка; после остановки возвращается обычный статус.
- Управление компьютером только с разрешённых Discord-аккаунтов, с подтверждением на ПК по желанию.
- Выход бота из голосового канала по команде.
- Голосовое управление участниками: перемещение, серверный мут микрофона и звука, отключение от канала и исключение с сервера. Отдельный список доверенных аккаунтов, голосовые имена и подтверждение номера человека.

Плагин работает в Windows, пока запущены Astra и сам плагин. Кнопка **Подготовить музыку** найдёт установленный [FFmpeg](https://ffmpeg.org/download.html) или загрузит его для плагина. Для локальных моделей распознавания и голоса нужен Python.

## Подключение бота

1. Скачайте `.astraplugin` из [Releases](https://github.com/Voltur792/VC-Discord/releases/latest) и импортируйте в Astra. Откройте вкладку **VC-Discord**.
2. В [Discord Developer Portal](https://discord.com/developers/applications) создайте приложение и добавьте ему бота. Получите токен в разделе **Bot**. Для обычного приглашения бота отключите **Requires OAuth2 Code Grant**, если этот параметр включён.
3. Пригласите бота на сервер через **OAuth2 → URL Generator**, выбрав область **bot** и разрешения **View Channels**, **Connect**, **Speak**. Для подключения нужен доступ к выбранному голосовому каналу.
4. Во вкладке **Подключение** введите токен, нажмите **Найти серверы и голосовые каналы** и выберите нужный канал. Можно указать ID сервера и канала вручную.
5. Настройте голос и модель, сохраните параметры и нажмите **Войти в канал**. Кнопка **Проверить голос** произнесёт тестовую фразу в Discord.

Для обычной установки нужен именно файл **`.astraplugin`**. **Source code (zip)**, **Source code (tar.gz)** и **Code → Download ZIP** содержат исходники без собранного файла запуска. Их нельзя сразу загрузить через **Plugins → Dev**: сначала выполните сборку по инструкции ниже.

Токен вводится только в плагине. Для копирования ID включите **Режим разработчика** в настройках Discord → **Расширенные**.

## Голос и модель

Для быстрой настройки нажмите **Использовать всё из Astra** сверху. Плагин выберет её чат, распознавание речи и доступный голос Supertonic. Выбор чата и распознавания следует настройкам Astra; голос можно повторно импортировать после его изменения.

Во вкладке **Голос и модель** можно настроить каждый источник отдельно:

- **Распознавание:** выберите Whisper, Vosk, Google Web STT или свой сервис. Для локального распознавания используйте кнопки подготовки модели; при наличии моделей в Astra можно взять её настройки. Google отправляет речь в свой сервис и включается после разрешения в настройках.
- **Чат:** выберите совместимое подключение Astra или свой сервер, укажите модель и нажмите **Найти модели**. Для локальной модели запустите сервер в LM Studio или другом совместимом приложении. Поддерживаются подключения с Chat Completions API; нативные API Claude и Gemini напрямую не импортируются.
- **Ключи:** ключ выбранного провайдера вводится отдельно один раз и сохраняется для этого подключения. При переключении провайдера используется его собственный сохранённый ключ. Защищённый ключ из Astra автоматически не импортируется.
- **Озвучка:** для Supertonic выберите **Голос Astra — Supertonic 3** и нажмите **Взять текущий голос Astra**. Для Windows нажмите **Найти установленные голоса**; можно также настроить свой сервис озвучки.
- **Личность:** включите использование текущей личности Astra. Выбранная модель получает описание характера; для облачного подключения проверьте получателя и сохраните разрешение. Личная память и история чатов Astra в общий разговор не передаются.

Обычные разговоры слышат все участники. История общего разговора хранится до отключения бота; её можно очистить кнопкой во вкладке.

## Доступ к управлению

Во вкладке **Доступ к ПК** добавьте Discord ID доверенных аккаунтов. Именно эти аккаунты могут управлять музыкой, обсуждать экран и отключать бота голосом. Никнейм или произнесённый пароль не дают доступ.

Для команд компьютеру дополнительно включите **Разрешить команды на ПК** и задайте фразу **Астра выполни**. По умолчанию действие требует подтверждения во вкладке; подтверждение можно отключить. Ответ на команду компьютеру виден только на этом ПК.

Если при выполнении команды Astra сообщает, что командный чат недоступен для импортированного пакета, используйте установку из исходников через **Plugins → Dev**, предварительно выполнив сборку.

## Управление участниками

1. Откройте **Участники**, включите **Разрешить управление участниками** и добавьте Discord ID тех, кто может отдавать команды. Этот список независим от доступа к ПК; кнопка **Взять список доступа к ПК** позволяет скопировать его. Сохраните настройки.
2. В Discord выдайте роли бота **Move Members**, **Mute Members**, **Deafen Members** и, если нужно исключение с сервера, **Kick Members**. Для переноса нужны **View Channel**, **Connect** и **Move Members** в канале назначения. Для кика роль бота должна быть выше роли участника; владельца сервера исключить нельзя. Во вкладке показаны текущие права бота, а перед действием они проверяются повторно.
3. Подключите бота. У каждого человека в списке справа появится номер, у доступных голосовых каналов — номер во вкладке **Участники**. Номера привязаны к Discord ID и сохраняются до переподключения; вышедший человек не передаёт свой номер новому участнику.
4. Для сложного ника нажмите **Голосовое имя** и добавьте удобные формы: `Discord ID = Саша, Сашу, Саше`. Так же можно задать простое имя каналу: `ID канала = Игровая, игры`. Сохраните настройки. Можно всегда обращаться по номеру вместо имени.
5. Скажите **«Астра, замуть участника два»**. Бот повторит имя человека и действие. Проверьте ответ и скажите **«Астра, подтверди участника два»**. Для переноса бот также повторит канал назначения. Подтвердить может только аккаунт, который отдал команду, в течение минуты.

Если имя не совпало или подходит нескольким людям, бот перечислит номера. Скажите **«Астра, выбери участника два»**, дождитесь повторения имени и действия, затем подтвердите номер. Выбор по приблизительному звучанию автоматически не выполняется. Список можно услышать командами **«Астра, назови участников»** и **«Астра, назови каналы»**.

Команда **«Астра, отмени команду»** отменяет ожидающее управление участником. Оно также отменяется при сохранении настроек, остановке ответа, очистке истории, отключении бота или выходе говорящего. Выбирать можно людей, находящихся в голосовом канале бота; если человек вышел или сменил канал до выполнения, запрос нужно повторить. Все команды требуют обращения по выбранному имени бота, даже если обычный разговор настроен после каждой реплики.

**«Кикни Сашу»** означает отключение от голосового канала. **«Кикни Сашу с сервера»** означает исключение с сервера. Серверный мут отличается от выключенного самим участником микрофона: команда снятия мута не включает его собственный микрофон. После переноса или отключения бот перестаёт слышать человека в другом канале.

### Установка из исходников через Plugins → Dev

1. Установите Node.js 22.12 или новее с npm. Скачайте и распакуйте исходники плагина.
2. Откройте PowerShell в распакованной папке, где находятся `plugin.toml` и `package.json`, и выполните:

   ```powershell
   npm.cmd ci
   npm.cmd run build
   ```

3. Дождитесь успешного завершения обеих команд. В папке появится файл `dist/index.js` и необходимые компоненты голоса.
4. Загрузите эту папку в Astra через **Plugins → Dev** и включите плагин.

Ошибка `Cannot find module '…\dist\index.js'` означает, что файл запуска отсутствует. Если вы скачали архив исходников, выполните сборку или импортируйте готовый `.astraplugin` из Releases.

## Музыка в Discord

1. Установите [Astra Music 1.1.6 или новее](https://github.com/Voltur792/astra-music/releases/latest), включите её и подключите Яндекс Музыку или VK. После обновления выключите и включите оба плагина.
2. Подключите Discord-бота к каналу и откройте **VC-Discord → Музыка**.
3. Нажмите **Подготовить музыку**. Если FFmpeg не найден, плагин скачает его с gyan.dev (около 109 МБ), проверит целостность и сохранит в своей папке. Интернет нужен для загрузки; системные настройки и PATH не меняются. Дождитесь сообщения **Музыка готова**.
4. Найдите песню, выберите плейлист, включите «Мою волну» или «Мои треки VK». Кнопка **Показать текущий трек Astra Music** позволяет взять выбранную в её плеере песню.
5. Управляйте очередью кнопками или голосом. Ползунок показывает текущую громкость, в том числе после голосовой команды.

Выбранные в VC-Discord треки звучат только в Discord и не запускают плеер на компьютере. После обновления интеграции перезапустите оба плагина.

## Обсуждение экрана

1. Загрузите на этом ПК локальную модель с поддержкой изображений и укажите её во вкладке **Голос и модель**.
2. Добавьте свой Discord ID в **Доступ к ПК**. Для просмотра экрана разрешать команды компьютеру необязательно.
3. Во вкладке **Экран** отметьте поддержку изображений, сохраните настройки и подключите бота.
4. Нажмите **Выбрать экран в браузере**, выберите окно или монитор и оставьте открывшуюся страницу открытой.
5. Вернитесь в плагин и нажмите **Показывать экран**. Задайте вопрос о том, что на экране.

К реплике разрешённого аккаунта добавляется свежий снимок выбранного экрана. Снимки передаются только локальной модели на этом ПК; звук экрана не передаётся. Ответ слышат все участники канала. Кнопка **Остановить показ экрана** выключает передачу снимков. После отключения, сохранения настроек или перезапуска экран нужно выбрать заново.

## Диагностика

Блок **«Диагностика»** проверяет компоненты при запуске плагина и после ошибок. Кнопка **«Проверить ещё раз»** обновляет результаты для сохранённых настроек.

- Проверяются PowerShell и его политика запуска, шифрование пробной строки, запись в папку настроек, Python и пакеты выбранного распознавания, файлы моделей, голоса Windows и FFmpeg.
- Для каждой найденной проблемы показаны код и способ исправления. Пакеты Vosk, Whisper и FFmpeg можно подготовить кнопками рядом с результатами проверки.
- Установленные Python и PowerShell находятся напрямую, даже если они отсутствуют в PATH. Системные переменные среды и политика безопасности автоматически не изменяются.
- **«Скачать отчёт»** сохраняет результаты для передачи разработчику. В отчёте нет ключей, токена Discord, речи, истории разговора и путей к личным файлам.

Автодиагностика не загружает большие модели и не воспроизводит звук. Соединение с моделью проверяется кнопкой **«Найти модели»**, а реальная озвучка — **«Проверить голос»** после подключения бота к каналу.

В статусе бота отображается, например, **«VK • Кино — Группа крови»** или **«Яндекс Музыка • исполнитель — песня»**. На паузе появляется отметка **«Пауза»**; после остановки статус сбрасывается. Обновление может занять несколько секунд.

Astra Music последовательно загружает части музыкального файла и повторяет запрос недополученного фрагмента при временном обрыве. Если восстановление не удалось, очередь останавливается с сообщением об ошибке. Следующая песня запускается автоматически после успешного завершения текущей. При повторной ошибке обновите и перезапустите оба плагина, проверьте подключение музыкального сервиса и включите трек заново.
