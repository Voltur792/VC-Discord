Диагностика Проверяем компоненты…

Проверка запускается автоматически при включении плагина и после ошибок. Проверяются сохранённые настройки. Пакеты и программы устанавливаются только кнопками подготовки.

    Отчёт содержит версии программ, результаты проверок и код последней ошибки. Ключи, токен бота, речь, история и пути к личным файлам в него не включаются.

    Подтвердить команду на ПК

    Ваш Discord-бот

    Добавьте бота на сервер с правами просматривать канал, подключаться и говорить.

    Токен хранится зашифрованным под вашим Windows-аккаунтом.

    Если бот ещё не приглашён, откройте ссылку в браузере, где вы вошли в Discord. Затем повторите поиск.

    Ошибка «Integration requires code grant» при приглашении: в Developer Portal → ваше приложение → Bot → Authorization Flow выключите Requires OAuth2 Code Grant и нажмите Save Changes.

    Где взять токен и ID?
    1. Откройте Discord Developer Portal, создайте приложение и бота в разделе Bot. Скопируйте токен.
    2. В OAuth2 → URL Generator выберите bot и права View Channels, Connect, Speak. Перейдите по ссылке приглашения и добавьте бота на сервер. Права администратора не нужны.
    3. В Discord включите Настройки → Расширенные → Режим разработчика.
    4. Нажмите правой кнопкой по серверу, голосовому каналу или аккаунту и выберите «Копировать ID».

    Как начинается разговор

    Распознавание речи

    Поддерживаются Whisper и Web Speech-to-Text. Для перехода на Google требуется разрешить отправку речи ниже.

    Использует уже скачанную модель Whisper из Astra. Речь обрабатывается на этом ПК в отдельном процессе и не сохраняется в файлы. Большая модель точнее, но требует больше памяти и времени.

    Установит движок в отдельное окружение плагина. Уже скачанная модель Astra используется без повторной загрузки.

    Распознаёт звук из Discord через Google, как Web Speech-to-Text в Astra. Нужен интернет; общий бесплатный доступ может быть ограничен Google. Используется отдельное подключение без управления плагином Web STT.

    Поддерживается OpenAI-совместимый адрес /audio/transcriptions. При облачном API речь отправляется выбранному сервису.

    Речь распознаётся на вашем ПК. Нужен Python с пакетом vosk и распакованная русская модель.

    Создаст отдельное окружение и скачает небольшую русскую модель, около 45 МБ.

    Личность Astra

    Берёт текущее описание личности Astra перед каждой репликой. Изменения характера подхватываются автоматически. Если описание пустое, используется обычный характер бота.

    Модель для общего разговора

    Модель получает общий разговор. При включённом показе экрана она также получает выбранные снимки. Можно использовать локальную модель в LM Studio.

    Берёт текущие модель и адрес выбранного подключения Astra перед каждой новой репликой. Для каждого провайдера используется его сохранённый ключ из плагина. Личная история и инструменты Astra в общий разговор не передаются. Для ручного выбора выключите эту настройку. Снимки по-прежнему разрешены только локальной модели.

    Голос ответов

    Использует скачанные файлы модели Astra, выбранный голос и скорость. Звук направляется в Discord.

    Провайдер должен поддерживать /audio/speech и выдавать PCM 24 кГц.

    Астра видит твой экран

    Пока показ включён, к каждой реплике разрешённого аккаунта добавляется свежий снимок выбранного экрана. Ответ слышат все участники канала.

    Нужна локальная модель с поддержкой изображений во вкладке «Голос и модель». Плагин передаёт снимки только серверу на этом ПК: 127.0.0.1, localhost или ::1. Внешние адреса для снимков запрещены.

    Открыть окно выбора экрана

    Добавь свой Discord ID в список во вкладке «Доступ к ПК». Сначала сохрани настройки и подключи бота, затем выбери экран в браузере. Для обсуждения экрана разрешать команды на ПК не обязательно. Реплики остальных участников не передают снимки.

    Оставь вкладку выбора экрана в браузере открытой. Плагин хранит последний кадр только в памяти этого ПК. Показ выключается при закрытии вкладки, отключении бота, сохранении настроек и перезапуске плагина. После изменения настроек экран нужно выбрать заново. Нажатие «Остановить показ экрана» отменяет текущий ответ; уже отправленный запрос мог быть обработан моделью.

    Музыка в Discord

    Используются подключения Яндекс Музыки и VK из Astra Music. Выбранные здесь треки звучат только в голосовом канале Discord.

    Найдёт FFmpeg на этом ПК или загрузит его для плагина, около 109 МБ. Системные настройки не меняются.

    Плейлисты

    Astra Music должна быть включена. Голосовое управление доступно аккаунтам из списка «Доступ к ПК»: «Астра, включи песню …», «Астра, включи плейлист …», «Астра, включи мою волну», «Астра, громкость 5», «Астра, музыку тише», «Астра, следующий трек».

    Остальные участники могут разговаривать с ботом. Доступ к ПК проверяется по ID аккаунта, независимо от ника.

    Один ID на строку. Можно добавить участника кнопкой в списке канала.
